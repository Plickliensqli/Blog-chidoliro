Cómo llevarlo al blog

  1. Si hay imagen o canción, abre la carpeta de imágenes o la de música. Usa Add file → Upload files → Commit changes.
  2. Escribe aquí la ruta del archivo, como assets/imagenes/mi-dibujo.webp, completa la entrada y pulsa Descargar entrada para publicar.
  3. Abre la carpeta de publicaciones y sube el archivo JSON descargado con Add file → Upload files → Commit changes.
  4. Revisa Actions. Cuando “Publicar blog” termine con una marca verde, recarga el blog.

Para corregir algo, importa la entrada, conserva su nombre para el enlace, descarga la nueva versión y reemplaza el archivo anterior. Un borrador lleva draft: true y no aparece en el blog, pero si lo subes al repositorio público cualquier persona podrá leer el archivo.
